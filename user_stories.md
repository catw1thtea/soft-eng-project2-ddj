# User stories (paste each as its own GitHub Issue)

Sprint 1

1. As a new user, I want to create an account so that my reviews are tied to my name.
2. As a returning user, I want to log in and out so that only I can post under my account.
3. As a moviegoer, I want to post a star rating and written review of a film so that I can share my opinion.
4. As a user, I want to see a feed of the latest reviews from everyone so that I can discover what people are watching.

Sprint 2

5. As a user, I want to open a film's page and see all of its reviews and its average rating so that I can decide whether to watch it.
6. As a reviewer, I want to edit one of my reviews so that I can fix mistakes or update my opinion.
7. As a reviewer, I want to delete one of my reviews so that I can remove something I no longer stand behind.
8. As a user, I want to search for films by title or genre so that I can quickly find what I'm looking for.
9. As a user, I want a profile page listing all my reviews so that I can keep track of what I've watched.
10. As a user, I want to see other people's profiles so that I can find reviewers whose taste matches mine.
